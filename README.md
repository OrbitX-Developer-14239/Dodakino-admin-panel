# DODA KINO — Admin Panel

![Doda Kino Preview](public/og-image.png)

**Doda Kino Admin Panel** — bu Telegram orqali bepul kino va serial ulashuvchi **Doda Kino** botini boshqarish uchun yaratilgan zamonaviy boshqaruv paneli. Ushbu loyiha zamonaviy texnologiyalar asosida ishlab chiqilgan bo'lib, bot kontenti, foydalanuvchilar va majburiy obuna kanallarini qulay tarzda boshqarish imkonini beradi.

## Admin Panel haqida

Doda Kino Admin Panel orqali jamoa **filmlar va seriallarni qo'shish, tahrirlash va o'chirish**, **majburiy obuna kanal/guruhlarni boshqarish**, **statistika va foydalanuvchilar oqimini kuzatish** kabi vazifalarni bitta joydan bajarishi mumkin.

Panel Doda Kino Telegram bot ehtiyojlarini chuqur o'rganib, jamoa a'zolari uchun eng moslashtirilgan va soddaligi bilan ajralib turuvchi interfeysni taklif qiladi.

## Admin Panel imkoniyatlari

✅ **Filmlar va seriallarni boshqarish** (qo'shish, tahrirlash, o'chirish)
✅ **Majburiy obuna kanal/guruhlarni sozlash**
✅ **Bot statistikasi va foydalanuvchilar tahlili**
✅ **Admin hisoblarni boshqarish va ruxsatlar tizimi**
✅ **Xavfsiz va ishonchli autentifikatsiya (Telegram orqali login)**
✅ **Qulay va tezkor qidiruv/saralash tizimi**
✅ **Mobil, planshet va kompyuterlarga mos interfeys**

## Nima uchun Doda Kino?

Doda Kino — bu shunchaki Telegram bot emas. Bu foydalanuvchilarga bepul va qulay tarzda kino/serial ulashuvchi, shu bilan birga Telegram kanal va guruhlarga organik obunachi oqimini ta'minlovchi loyiha.

Ushbu admin panel **bot kontentini samarali boshqarish** maqsadida yaratilgan. Bugungi kunda yuzlab kino va serial nomlari Doda Kino platformasida mavjud bo'lib, ularning soni doimiy yangilanib boradi.
